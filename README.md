# Python Stopwatch

A simple stopwatch application built with Python and Tkinter.

## Features

- Start the stopwatch
- Stop/pause the stopwatch
- Resume the stopwatch
- Reset the stopwatch
- Record lap times
- Display hours, minutes, seconds, and centiseconds
- Simple graphical user interface

## Requirements

- Python 3.x
- Tkinter

Tkinter is normally included with Python.
